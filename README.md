# PTT Marvel 風格靜態版型

這是一個可直接放上 GitHub Pages 的 PTT 風格靜態網站，包含雙頁列表、日期排序、文章閱讀、發文、回文、推文與鍵盤快捷鍵。專案不需要安裝套件，新增內容會儲存在使用者自己的瀏覽器中。

開啟網站時會先顯示代號輸入封面；使用者按 Enter 進入看板後，發文、回文與推文會固定使用該代號，留言則直接保留在原文章下方。

搜尋框可即時搜尋目前頁面的文章分類、標題、作者、日期與內文；清空關鍵字即可恢復完整列表。

點選「精華區」可進入 PTT 終端機風格的目錄索引；頁面底部的「回到上層」可返回文章列表。

點選右上角「聯絡我們」可進入聯絡資訊頁面，並可由底部「回到上層」返回原頁面。

## 本機查看

直接用瀏覽器開啟 `index.html` 即可。

## 放上 GitHub Pages

1. 在 GitHub 建立一個 repository。
2. 將本資料夾內的 `index.html`、`styles.css` 與 `README.md` 上傳。
3. 在 repository 的 Settings → Pages 中，將部署來源設定為 `main` branch。

## 修改內容

- 文章資料：編輯 `index.html` 底部 `posts` 陣列。
- 顏色、字級與版面：編輯 `styles.css`。
- 桌面版與手機版的分界為 760px。

## 快捷鍵

- `←`／`→`：離開文章，回到原本的列表頁與捲動位置。
- `Ctrl+P`：發表文章。
- `y`：回覆目前文章。
- `X` 或 `%`：新增推文、噓文或箭頭留言。
- `h`：顯示快捷鍵說明。
- `Ctrl+X`：在編輯視窗中送出文章。
